# Roam Atlas — обновлённая версия

Готовый сайт с фронтендом и сервером на Python. Английский интерфейс по умолчанию, русский выбирается кнопкой RU.

## Как открыть

1. Распакуйте весь архив в отдельную папку.
2. В Windows дважды нажмите `start-local.cmd`.
3. Откройте http://127.0.0.1:8080 в браузере. Окно сервера оставьте открытым.

На этом компьютере скрипт использует уже установленный Python из среды Codex. На другом компьютере нужен Python 3.10 или новее. Скрипт также умеет найти установленный Python через `py` или `python`; если подходящей версии нет, покажет понятное сообщение и адрес загрузки.

При запуске через `start-local.cmd` аккаунты и поездки сохраняются в `data/orbit.sqlite3` внутри распакованной папки. Скрипт выбирает порт 8080 и отключает унаследованные настройки рабочей базы, индексации и администратора только для своего процесса. Это отдельная локальная база, а не данные прежнего сайта. Не публикуйте папку `data`.

Для собственного окружения можно запустить `python app.py` из папки проекта. Эта команда учитывает переменные окружения, включая `DATABASE_URL`; она не включает изоляцию локального запуска. Если порт 8080 уже занят, закройте ранее запущенное локальное окно сервера перед повторным запуском.

## Что добавлено

- 250 стран и территорий, каждая с локальной фотографией и указанием автора.
- Единый список стран в поиске и планировщике; 34 160 городов.
- Поиск на русском и английском, фильтр по континенту, избранное и сравнение трёх стран.
- Карточки стран, столицы, валюты, карты, путеводители и случайное направление.
- Светлая, тёмная и системная темы с сохранением выбора.
- Поездки, маршруты по дням, бюджет, список вещей, заметки, аккаунты.
- Выгрузка планов, календарь и печать/PDF.

## Размещение в интернете

Эта версия **ещё не опубликована**. В Sites включён общедоступный режим по вашему запросу, но размещённой версии пока нет. Исходный сайт на Render и его репозиторий не изменены. Публикация в Sites заблокирована ограничениями среды: автоматическая проверка отклонила подготовку исходников, а штатный инструмент получает отказ Windows при запуске служебного процесса.

При проверке 15 октября 2026 года прежний сервер `roam-atlas.onrender.com` возвращал HTTP 502. Это отдельно препятствует работе аккаунтов и поездок через подготовленную Sites-версию, которая подключается к прежнему серверу. Локальная Python-версия запускается независимо от него.

Для проверки ошибки и обновления прежнего сайта нужны подключённые GitHub и Render. Эти плагины найдены, но пока не подключены к беседе. Их подключение не снимает отдельное ограничение публикации через Sites.

## Работа при выключенном ноутбуке

Для этого вся Python-версия должна быть размещена на Render с постоянной серверной базой PostgreSQL. Локальный запуск из архива работает только при включённом компьютере. После успешного размещения сервер Render и его база работают независимо от ноутбука; это размещение пока не выполнено.

Если сервис использует бесплатный тариф Render, после 15 минут без посещений он засыпает, а при новом посещении просыпается примерно за минуту. Бесплатная база именно Render Postgres действует 30 дней, поэтому перед публикацией нужно проверить тип и срок действия уже подключённой базы. [Официальные ограничения Render](https://render.com/docs/free).

Для обновления прежнего Render-сайта используйте раздел «Update the existing Roam Atlas service» в `PUBLISHING.md`: он сохраняет существующую базу, аккаунты и поездки. Создание новой установки описано отдельно и означает отдельную пустую базу. Результаты проверок и ограничения — в `VERIFICATION.md`. Авторы всех фотографий — в `PHOTO-CREDITS.md`.
